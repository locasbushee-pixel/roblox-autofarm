# 👑 Solara AutoFarm v7.1 (Locas Edition)

سكربت أوتو فارم متطور للعبة Roblox، مصمم بدقة عالية بناءً على تحليل بيانات اللعبة الحقيقية (Data-Driven). يتميز بنظام ذكي لإدارة المهام، الدروبات، والكهف السيبراني مع واجهة تحكم متكاملة وحماية متقدمة ضد القيود والسجن.

## ✨ المميزات الرئيسية (Key Features)

### 🎯 نظام المهام الذكي (Smart Mission System)
- **كشف تلقائي للحالة:** يقرأ حالة المهمة مباشرة من واجهة اللعبة (`BoxMission`) والريموتات لمنع تداخل المهام.
- **دورة كاملة:** استلام الصندوق -> التوجه للهدف -> التسليم -> كول داون تلقائي.
- **حماية من التعليق:** إعادة ضبط الحالة تلقائياً إذا فقد الهدف أو تعطلت المهمة.

### 📦 نظام الدروبات المتقدم (Advanced Drop System)
- **انتقال فوري (Teleport):** ينتقل اللاعب فوراً فوق الدروب دون مشي لضمان السرعة.
- **ضغط حقيقي:** يستخدم برومبتات اللعبة الحقيقية + ضغط E + لمس لضمان الفتح.
- **حل كويز تلقائي:** يقرأ المعادلة من السيرفر (`AirdropQuizEvent`) ويحلها بدقة حتى للصناديق.
- **مالك واحد:** يمنع تضارب النسخ المتعددة ويضمن تنفيذ الأمر مرة واحدة بفعالية.

### 🕵️ كهف الأمن السيبراني (Cyber Cave - Walk Only)
- **ميكانيكا المشي فقط:** يدخل الكهف بالمشي الطبيعي لالتقاط النقاط (+50) دون استخدام انتقال أو ريسبawn.
- **إشارات دقيقة:** يعتمد على إشعارات اللعبة (`NotiEvent`) لفتح الباب وتجنب الرسائل التحذيرية.
- **تأكيد النقاط:** يتحقق من زيادة الرصيد في `leaderstats` قبل اعتبار المهمة منجزة.

### ️ أنظمة الحماية والدفاع (Defense & Anti-Jail)
- **مضاد الكلبشة (Anti-Cuff):** كشف وإزالة أدوات التقييد والكلبشات فوراً.
- **مضاد السجن (Anti-Jail):** هروب تلقائي عند اكتشاف نقل مفاجئ لمنطقة السجن.
- **درع تلقائي:** تفعيل الدرع وتجديد الصحة عند انخفاضها.
- **مضاد الرصاص:** استعادة الصحة فور التعرض للإصابة.

### 🎮 واجهة تحكم متكاملة (Full GUI)
- **6 تبويبات:** فارم، حركة، كشف (ESP)، خريطة (Radar)، أدوات، هجوم.
- **رادار تفاعلي:** يظهر اللاعبين والدروبات مع إمكانية الانتقال أو الكلبشة بنقرة واحدة.
- **تحكم كامل:** سرعة، قفز، طيران، Noclip، إضاءة، واختفاء.
- **سجلات تشخيصية:** تتبع كل خطوة (zDROP, zQUIZ, zCYBER) لمعرفة سبب أي مشكلة فوراً.

## ⚙️ طريقة الاستخدام
1. انسخ كود السكربت الرئيسي `Solara_AutoFarm_v7.1_Locas.lua`.
2. الصقه في منفذ السكريبت الخاص بك (Executor).
3. استخدم زر **Home** لإظهار/إخفاء الواجهة، و **End** لإيقاف السكربت تماماً.
4. جرب زر **"تجربة الدروب الآن"** للتأكد من عمل النظام قبل البدء.

## ️ ملاحظات هامة
